# Event Management System

## Project Title

Event Management System using React, Spring Boot and MySQL

---

## Project Overview

The Event Management System is a web-based application designed to simplify the process of organizing and managing events. The system allows administrators to create events, manage participants, track registrations, and generate reports.

The platform provides secure user authentication, event scheduling, participant registration, and event monitoring through an easy-to-use interface.

---

## Problem Statement

Managing events manually can be time-consuming and error-prone. Organizers often face challenges in handling registrations, scheduling events, and maintaining participant records. This project aims to automate the entire event management process.

---

## Objectives

- Create and manage events.
- Allow participants to register online.
- Maintain participant records.
- Generate event reports.
- Provide secure user authentication.
